# 预定间隔表下 Shellsort 的最优平均比较数

**摘要。** 本文研究均匀随机排列上、间隔表在读取输入前固定的 Shellsort。允许间隔表随输入长度变化，证明最优平均键比较数为 $\Theta(n\log n)$，并给出对所有 $n\ge2$ 成立的显式非渐近界。该上界由一族至多 $\lfloor\log_2n\rfloor$ 趟的预定表给出。证明以位移势函数为基础，通过有限 Fourier 分析建立三趟收缩估计，再用尺度递推控制整张表的比较成本。附录证明，在 $n=10^9$ 时，任何至多七趟的合法表均需至少 $50\,017\,307\,496$ 次平均键比较。

**关键词。** Shellsort；平均复杂度；预定间隔表；位移势函数；有限 Fourier 分析。

## 1. 模型与记号

设 $n\ge2$。输入为 $n$ 个互异键，等价地视为 $\{0,1,\dots,n-1\}$ 的均匀随机排列。槽号与秩均从 $0$ 起编号。

合法间隔表是 $\{1,\dots,n-1\}$ 中含 $1$ 的子集，按严格降序执行；所有合法表的集合记为 $\mathcal H_n$。间隔为 $h$ 的一趟将槽位按模 $h$ 分成各条链，并在每条链上执行普通无哨兵线性插入排序。表在读取输入前固定，同一长度的所有输入使用同一张表。

记 $C_w(\pi)$ 为表 $w$ 在输入 $\pi$ 上的键比较次数，包括使扫描停止的键比较。定义

$$
\mu_n(w)=\frac1{n!}\sum_{\pi\in S_n}C_w(\pi),
\qquad
m_n=\min_{w\in\mathcal H_n}\mu_n(w).
$$

这里先固定间隔表，再对输入取平均，最后在合法表中取最小值。比较成本仅计排序过程中发生的键比较。

| 记号 | 含义 |
|---|---|
| $p(x)$ | 秩 $x$ 当前所在的槽号 |
| $S_hp$ | 对间隔 $h$ 的各条链排序后的状态 |
| $F(p)$ | 全局位移 $\sum_x\lvert p(x)-x\rvert$，即 Spearman 足距 |
| $Q(p)$ | 平方位移和 $\sum_x(p(x)-x)^2$ |
| $F_h(p)$ | 一趟间隔 $h$ 排序前后的链坐标净位移总和 |
| $I_h(p)$ | 间隔 $h$ 的链内逆序总数 |
| $P$ | 已固定的若干趟所组成的前缀状态映射 |
| $X(P)$ | 每键平均平方位移 $\mathbb E_\pi Q(P(\pi))/n$ |
| $\widetilde W_n$ | 用于证明上界的预定见证表 |
| $W^\star_n$ | 达到最小值 $m_n$ 的最优表 |

正文以 $\log_2$ 表示二进对数；附录中的 $\log$ 表示自然对数。

## 2. 主定理

**主定理（预定表的最优平均比较数）。** 存在表族 $W^\star=(W^\star_n)_{n\ge2}$，其中 $W^\star_n\in\mathcal H_n$，对每个 $n$ 个互异键的输入均能正确排序，且

$$
\boxed{
\frac12\,n\log_2n
\ \le\ \log_2(n!)
\ \le\ \mu_n(W^\star_n)=m_n
\ \le\ (1+2^{165})\,n\log_2n
}.
$$

此外，对每个 $n\ge2$，存在至多 $\lfloor\log_2n\rfloor$ 趟的见证表 $\widetilde W_n\in\mathcal H_n$，满足

$$
\mu_n(\widetilde W_n)\le(1+2^{165})\,n\log_2n.
$$

因此，预定间隔表的最优平均比较数为 $\Theta(n\log n)$。

**注。** 表族按输入长度分别选取，不要求各表嵌套。趟数界适用于构造出的见证表 $\widetilde W_n$；最优表 $W^\star_n$ 由有限集上的最小化选出，两者可以不同。本文研究排序比较成本，表的生成时间另计。主定理确定最优均值的渐近阶，$\lim_{n\to\infty}m_n/(n\log_2n)$ 的存在性及其值仍待研究。

**附录命题（七趟有限排除）。** 当 $n=10^9$ 时，任何至多七趟的合法间隔表 $w$ 都满足

$$
\boxed{\mu_n(w)\ge50\,017\,307\,496.}
$$

该命题给出固定输入长度和趟数范围内的显式下界，其证明独立于主定理的上界构造。

## 3. 证明概述与篇章安排

上界的第一步是把比较次数归结为位移。链内逆序数与足距的关系给出

$$
C^{(h)}(p)\le\frac{2F(p)}h+n.
$$

结合 $F$ 的单调性与 $\mathbb EF(P)\le n\sqrt{X(P)}$，可知一个含 $\ell$ 趟、各间隔至少为 $H$ 的块，只要入口满足 $X(P)\le(LH)^2$，其期望比较次数就至多为 $\ell(1+2L)n$。

第二步建立三趟收缩。对满足 $c=b_j\ge9400$ 的递推种子，构造中心 $c$ 附近的有限菜单 $G_j$，并令

$$
B_{j,h}=S_hS_{b_{j+1}}S_{b_{j+2}}.
$$

有限 Fourier 分析给出逐状态不等式

$$
\frac1{|G_j|}\sum_{h\in G_j}Q(B_{j,h}p)
\le2^{-47}Q(p)+2^{98}cF(p).
$$

对已固定前缀产生的状态分布取期望后，菜单中存在一个公共间隔 $h$ 满足相应收缩界。按固定顺序选取这样的 $h$，即可在读取实际输入前确定下一块。第三步用尺度函数 $A(v)=(2^{115}v)^2$ 维持各块的位移预算，再由比较成本引理累加，得到主定理的上界。

下界将固定表的比较过程编码为前缀码，由 Kraft 不等式与 Jensen 不等式得到 $\mu_n(w)\ge\log_2(n!)$，再由配对乘积估计得到 $\log_2(n!)\ge\frac12n\log_2n$。

附录通过插入记录的可逆性，把排序比较数与记录熵联系起来；利用参考测度和第一趟的精确平均成本，分两种链长情形得到有限下界，并用显式有理包围完成数值判定。

## 5. 相关工作

Sedgewick 的研究问题包括标准 Shellsort 的 $O(n\log n)$ 平均比较上界，以及十亿键时平均比较次数低于五百亿的有限规模问题 [S]。本文分别研究预定表最优均值的渐近阶与至多七趟时的有限排除。

Jiang–Li–Vitányi [JLV00] 给出了任意间隔序列的平均复杂度下界。对每个固定正整数 $p$，其结果蕴含 $\Omega(n^{1+1/p})$ 的平均比较下界，因而固定趟数不能达到 $O(n\log n)$。本文的见证表允许趟数随 $n$ 增长。Project S 的 P01 研究固定三趟，证明该范围内的最优平均成本为 $\Theta(n^{3/2})$ [P01]；两项结果分别处理固定三趟与趟数可变的预定表。

Hu [H25] 对一条具体间隔序列进行了数值实验与稳定性拟合，所得形式为 $cn\ln n+dn^\lambda\ln n$（$\lambda<1$），并据此提出 $O(n\log n)$ 平均复杂度的推断。本文通过位移收缩与尺度构造，证明按输入长度选取的预定表族满足显式的 $O(n\log n)$ 平均比较上界。

确定性比较估计使用 Diaconis–Graham [DG77] 的逆序数与 Spearman 足距关系。本文的上界证明建立在三趟谱收缩及其跨尺度组合上；信息论下界则由固定表的比较决策树给出。
